Formatador de calendário, feito em Java
-
Um código simples que recebe dois números, um que representa o mês (exemplo: 12), e outro que representa o ano (ex.: 2000).
Com base nisso, uma formatação será realizada, organizando os dias do mês respeitando questões como:
* Número de dias no mês.
* Número de semanas no mês.
* Em que dia da semana começa o mês.
